KRDART · Guides

Korea DART data guides

  • Korean company financial statements API (English JSON) — Get income statements, balance sheets and cash-flow items for ~4,000 KOSPI/KOSDAQ companies as English-labelled JSON, sourced from DART filings.
  • OpenDART API in English: the practical gotchas — A practical English guide to Korea's OpenDART API: corp_code lookup, report codes, blank account_id in fnlttSinglAcnt, Korean account names, and how to avoid them.
  • Distress scores for KOSPI & KOSDAQ companies (Altman Z'' EM, Piotroski-style F) — Pre-computed Altman Z''-EM and Piotroski-style F-scores for Korean listed companies, with methodology and the FY2024 distribution across ~2,750 companies.
  • Korean listed company risk events (delisting, audit opinion, going concern) as an API — A daily English feed of risk events from DART filings for Korean listed companies: delisting risk, audit opinion issues, going-concern doubt, collateral, lawsuits, capital changes.
