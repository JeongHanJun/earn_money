# 출시 노트 초안 (v1.0.2)

## 콘솔 붙여넣기용 (권장)

```
[v1.0.2 재제출] 이전 반려 사유(테스트 광고 그룹 ID 사용) 조치.

- 실제 발급받은 광고 그룹 ID로 교체 (라이언랩 워크스페이스 배너 그룹)
- 데이터 서빙 API 최신화 (data.ryanpp.com → api.ryanpp.com, 매시간 자동 갱신)
- 나머지 기능·권한·데이터 출처는 v1.0.1과 동일 (기상청·온통청년·Google Trends)
- 금지 카테고리(금융·의료·정치·부동산·자동차) 포함하지 않음
```

## 짧은 버전 (심사 노트 필드가 좁으면)

```
[v1.0.2] 반려 조치: 테스트 광고 ID → 실 광고 그룹 ID 교체. 데이터 API 최신화 파이프라인 구축. 기능·권한·데이터 출처 v1.0.1과 동일.
```

- `data/trends/kr.json` 실시간 급상승 최신
