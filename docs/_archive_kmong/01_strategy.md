# 사업 전략 v1 (2026-08-19)

## 한 줄 정의
**한국 B2B SaaS/에이전시의 해외 GTM 파트너**. AI 스택(Clay+Smartlead 대체 자체 파이프라인) + 한국어 커뮤니케이션 + 시그널 기반 타겟팅으로 미국 에이전시 가격의 1/3에 콜드아웃리치를 대행.

## 왜 지금 왜 우리
1. **한국 공백**: 크몽/숨고/네이버에 "AI 해외 콜드아웃리치 대행" 카테고리 사실상 없음. 국내 B2B 리드젠(SEGAMA, HyperM 등)은 국내 마케팅 중심.
2. **미국 언더컷**: Belkins/CIENCE $4K-10K/월. 우리 $1.5K-3.5K/월. 한국 SaaS 컨텍스트 이해도 우위.
3. **정부 매칭**: KOTRA 2026 서비스 BM 해외진출 지원사업 (80개사 모집, ICT/SaaS 포함) → 벤더 등록 시 리드풀 확보.
4. **AI 스택 진입장벽**: Clay $149-800/월 + Smartlead $94-174/월 + 워밍업 툴 조합을 DIY 하기 어려운 한국 회사가 대다수.

## 상품 정의 (v1)

### Package A: Starter (₩150만원/월)
- 월 300 qualified leads (ICP 필터)
- 3-step 개인화 이메일 시퀀스
- 오픈/클릭/답장 대시보드
- 주간 리포트 + 카피 튜닝
- 인프라(도메인 워밍업, 발송, 트래킹) 포함가

### Package B: Growth (₩250만원/월)
- 월 700 qualified leads
- 4-step 시퀀스 + LinkedIn 커넥션 요청
- 시그널 트리거 (펀딩/hiring/tech-stack 감지)
- 답장 1차 응대 초안 제공
- 미팅 부킹 캘린더 연동

### Package C: Scale (₩400만원/월, 협의)
- 무제한 lead volume (도메인 여러개)
- 멀티 페르소나 캠페인
- 전담 카피 튜닝 세션 주 1회
- 커스텀 시그널 정의

**락인**: 3개월 최소. 셋업비 ₩50만원 (도메인/워밍업/온보딩).

## 우리 자신의 GTM (첫 5고객 확보 90일 플랜)

### Track 1: 크몽/숨고 (즉시 신뢰 캐치)
- 크몽 "해외 콜드아웃리치 대행" 카테고리 선점 (최초 진입자)
- ₩100만원~₩300만원 견적으로 첫 3건 무료에 가까운 파일럿 → 후기 확보

### Track 2: LinkedIn/이메일 다이렉트 아웃리치 (Dogfooding)
- 한국 B2B SaaS 창업자/GTM 리드 300명 리스트
  - Rocket Punch, Wanted, LinkedIn Sales Navigator
  - 시리즈 A-B 투자 뉴스 (더브이씨, 마켓인) 크롤링
- 우리 시스템으로 우리 시스템 판매 → 최고의 신뢰 증거

### Track 3: KOTRA 지원사업 벤더 등록
- 2026 서비스 BM 해외진출 지원사업 벤더 pool 진입 조사
- 매칭펀드 50~80% 활용 가능한 포지션 확보

## 리스크 & 대응

| 리스크 | 대응 |
|---|---|
| 첫 파일럿에서 미팅 부킹 실패 → 이탈 | 최소 3개월 락인 + 셋업비. 파일럿 KPI를 "미팅"이 아니라 "positive reply rate"로 정의 |
| 도메인 스팸 등록 (Google/Yahoo 강화) | 별도 도메인 + IP + 6주 워밍업. 클라이언트 메인 도메인 절대 사용 X |
| Clay/Smartlead 카피캣이라는 인식 | "우리는 툴을 파는 게 아니라 결과를 판다" + Clay/Smartlead보다 저렴한 이유는 대행 규모의 경제 |
| 리드 데이터 소스 legality | Apollo/Lusha 정식 API + 공개 LinkedIn만. 스크레이핑은 회색지대 최소화 |
| 서비스 quality inconsistency | 카피 생성 → Claude 이중 검수 → 인간 최종 서명. Golden prompt 라이브러리 축적 |

## 자산화 로드맵

- **Month 1-6**: 대행 (에이전시 모드). 5~10 고객, 월 ARR ₩1500만~4000만.
- **Month 6-12**: 축적된 파이프라인 + 프롬프트 + 워크플로우를 **SaaS화**. Self-serve tier $99-499/월. 기존 고객을 anchor customer로 전환.
- **Month 12-24**: SaaS ARR 목표 ₩10억. 매각가치 ₩50-100억.
