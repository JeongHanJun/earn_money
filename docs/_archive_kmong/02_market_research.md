## 2. 미국/유럽 B2B 콜드메일 에이전시 가격

**대표 에이전시**: Belkins (Clutch 4.9/5), CIENCE, Martal Group (SaaS 특화), SalesRoads (phone-first), SalesCaptain (시그널 기반).

**서비스 스코프**: 리드 리서치 → 도메인/인박스 셋업 → 리스트 빌딩 → 카피라이팅 → 시퀀스 발송 → 응답 처리 → 미팅 부킹. **3-6개월 락인, 3-4개월 램프업**.

## 3. 한국 시장 현황 (공백 = 기회)

- **국내 B2B 리드젠 대행사**: SEGAMA, HyperM 등 — 대부분 **국내 B2B + 광고 캠페인** 중심
- **해외 콜드아웃리치 전문**: 사실상 부재
- **크몽/숨고**: "콜드메일 대행" 전문 서비스 검색 결과 거의 없음
- **트랜스코스모스 코리아**: 아웃바운드 콜센터, B2B AI 개인화와 결이 다름
- **채널톡**: 내부 SDR 팀 (자기용, 대행 X)

**결론**: "AI 개인화 + 해외 리드 + retainer + 한국어 커뮤니케이션" 조합의 프로바이더 공백. Clay/Smartlead 스택 세팅 자체가 진입장벽이라 DIY 하기 어려운 한국 B2B SaaS 다수 존재.
